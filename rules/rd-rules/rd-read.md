# 技术选型文档

## 核心技术栈
- **Web框架**: FastAPI (异步支持好，自动生成文档)
- **任务队列**: Celery + Redis (成熟稳定)
- **数据库**: PostgreSQL (JSONB支持，分区表)
- **缓存**: Redis (高性能，支持多种数据结构)
- **AI服务**: gemini API + open router ai proxy
- **监控**: Prometheus + Grafana
- **日志**: Loguru 

## 第三方服务
- **图片存储**: 阿里云OSS / MinIO
- **爬虫框架**: Playwright (动态页面支持)
- **定时任务**: APScheduler
