# 内容审核模块详细设计文档

## 1. 模块概述

### 1.1 模块定位
内容审核模块是确保内容质量、合规性及平台安全的关键防线。它在内容生成之后、账号匹配与发布之前运行，通过自动化工具和人工审核相结合的方式，对所有待发布内容进行全面检查。

### 1.2 核心目标
- **合规性保障**：确保内容严格遵守国家法律法规、今日头条平台规则及其他相关政策，特别是关于AIGC内容的生成、标注、版权和信息真实性的要求。
- **质量控制**：提升内容的可读性、逻辑性和专业性，确保内容信息准确无误，符合账号的定位和风格调性。
- **风险规避**：主动识别并拦截涉政、涉黄、涉暴、低俗、引战、谣言等不良信息，以及可能损害平台、MCN或账号声誉的潜在风险内容。
- **原创性维护**：辅助判断内容的原创程度，避免发布高度重复或洗稿性质的内容，保护原创环境。
- **用户体验提升**：通过高质量、安全合规的内容，提升终端用户的阅读体验和平台信任度。

### 1.3 关键指标
- **审核准确率**：机审准确识别风险内容的比例 > 90%；人审误判率 < 2%。
- **审核覆盖率**：100% 的内容在发布前经过审核流程。
- **审核效率**：
    - 机审平均耗时 < 10秒/篇。
    - 人审平均耗时（对于需人工介入的内容）< 3分钟/篇。
- **风险拦截率**：对高危风险内容的拦截率 > 99%。
- **申诉率**：因审核问题导致的发布后内容下架或用户申诉率 < 0.1%。

## 2. 审核流程设计

### 2.1 整体审核流程

    C -- 低风险/通过初筛 --> E(内容发布准备);
    D -- 审核通过 --> E;

    D -- 修改后提交 --> B;

        C4[质量与可读性评估]

    C --> C1;
    C1 --> C2;
    C2 --> C3;
    C3 --> C4;
    C4 --> C5;

    subgraph "人工审核层"
        D1[内容详情展示]

2.2 流程说明
进入审核队列：内容生成模块完成后，将内容（文本、图片、元数据等）推送到审核队列。
自动化审核：系统自动执行一系列预设的审核任务：
合规性检查：检查AIGC内容是否按要求标注，版权信息是否初步声明等。
敏感词与违禁内容检测：基于更新的敏感词库、黑名单库，检测黄、赌、毒、暴恐、涉政等内容。
原创性与重复度检测：与历史已发布内容库、互联网公开内容进行比对，评估原创性，识别洗稿、搬运。
质量与可读性评估：使用NLP技术评估文章的流畅度、逻辑性、是否存在错别字、语句不通顺等问题。图像内容则检查清晰度、是否包含不当水印等。
风险分类与评分：综合以上检测结果，对内容进行风险评估，输出风险等级（如：高、中、低）和置信度分数。
分流决策：
高风险/存疑内容：自动化审核判定为高风险，或某些指标低于阈值（如原创度过低），或触发了特定敏感规则的内容，自动进入人工审核队列。
低风险/通过初筛内容：自动化审核认为风险较低且质量基本达标的内容，可以直接进入内容发布准备阶段，或根据配置进行人工抽检。
人工审核：审核员在工作台对分配到的内容进行详细审查。
重点关注机审标记的风险点。
进行事实核查，判断内容的真实性和准确性。
评估内容的深度、价值和风格是否符合账号定位。
做出审核决策：通过、拒绝（需说明理由）、或退回修改（需给出修改建议）。
审核结果处理：
审核通过：内容进入发布准备阶段。
审核拒绝：内容被标记为不合格，归档或删除，相关数据用于模型优化。
修改后提交：内容返回内容生成或编辑环节进行修改，修改完毕后重新进入审核队列。
内容发布准备：等待发布的合规内容。
内容发布：内容被推送到发布调度模块。
3. 审核策略与规则
3.1 自动化审核策略
3.1.1 合规性检查
AIGC内容标注：
规则：检查内容是否包含AI生成声明（如特定标签、文本声明）。
处理：未标注或标注不规范的，标记为“合规性风险”，提示人工检查或自动补充。
版权信息：
规则：检查图片、引用内容是否包含来源信息或版权声明。
处理：缺失版权信息的，标记风险，提示人工核实。
外部链接检查：
规则：检测内容中的URL，是否存在恶意链接、赌博、钓鱼网站。
处理：发现可疑链接，标记高风险。
3.1.2 敏感词与违禁内容检测
敏感词库：
类型：涉政、涉暴、涉恐、涉黄、辱骂、广告法违禁词、低俗等。
管理：词库应支持分级（如：绝对禁止、警告、一般敏感），并能动态更新。
技术：采用AC自动机、正则表达式等高效匹配算法。
图片审核 (Vision API)：
检测项：色情内容、暴力血腥、政治敏感人物/标识、二维码、不良水印。
处理：根据检测结果和置信度，标记不同风险等级。
变体词处理：
规则：识别通过拼音、谐音、拆字、特殊符号等方式规避的敏感词。
技术：结合词向量模型、NLP理解进行判断。
3.1.3 原创性与重复度检测
文本相似度比对：
技术：SimHash, TF-IDF + Cosine Similarity, 编辑距离等。
比对库：系统已发布内容库、互联网公开爬取的热点文章库。
阈值：根据不同内容类型和账号要求设定不同的相似度阈值（如：>80% 判定为高度疑似抄袭，60%-80% 疑似洗稿）。
图片相似度比对：
技术：感知哈希 (pHash, aHash, dHash), SIFT, SURF 特征点比对。
比对库：系统已用图片库、常见版权图片库。
3.1.4 质量与可读性评估
文本质量：
指标：错别字率、语法错误、句子流畅度 (Perplexity)、逻辑连贯性、关键词密度。
技术：NLP库 (如spaCy, NLTK), 语言模型。
处理：质量评分过低的内容，标记为“低质量”，建议人工优化。
图片质量：
指标：清晰度、亮度、对比度、是否有过度压缩痕迹、是否包含大面积纯色块或噪点。
技术：图像处理库 (如OpenCV, Pillow)。
3.1.5 风险分类与评分模型
综合评分：结合以上所有自动化审核模块的输出，通过加权算法或机器学习模型，对每篇内容生成一个综合风险评分和风险等级。
规则引擎：允许配置复杂的审核规则，例如：“如果内容类型为财经，且包含3个以上‘高风险’级别涉政敏感词，则直接判定为高风险并转人工审核。”
3.2 人工审核标准与指南
3.2.1 审核优先级
高风险内容优先：机审标记为高风险的内容，或来自重点监控账号的内容，具有最高审核优先级。
时效性内容优先：如突发新闻、热点事件解读，需要快速审核。
3.2.2 审核要点
事实准确性：
对内容中涉及的关键事实、数据、引言进行核查。
对于健康、科普、财经等专业领域内容，确保信息来源可靠，观点科学。
价值判断：
内容是否具有独到见解或实用价值。
是否符合目标用户的阅读兴趣和需求。
是否传递积极正向的价值观。
观点与情感倾向：
内容观点是否客观中立，或虽有倾向但表达合理。
避免极端、片面、煽动性或引战言论。
检查是否存在不当的情感导向。
风格与调性：
内容风格是否与发布账号的定位一致。
语言表达是否符合账号的人设和目标受众。
图片与多媒体审核：
图片与文字内容是否相关。
图片是否清晰、美观，无不良引导。
视频（如果支持）是否有声音、字幕问题，内容是否合规。
最终合规性把关：
对机审可能遗漏的隐晦表达、深层含义进行判断。
结合当前社会热点和平台政策动态，进行综合判断。
3.2.3 审核决策标准
通过 (Pass)：内容合规、质量达标，无明显风险。
拒绝 (Reject)：
存在严重违规（如涉政敏感、色情、谣言）。
内容质量低下，缺乏基本可读性。
抄袭或高度重复。
（需详细记录拒绝理由，供后续分析和申诉）。
修改 (Edit/Revise)：
存在少量敏感词或不当表述，可简单修改。
事实性小错误，可修正。
排版、错别字等问题。
（需给出明确的修改建议）。
4. 技术架构与实现
4.1 核心组件
审核任务队列 (Task Queue)：如Celery + Redis/RabbitMQ，接收待审核内容，分发给审核服务。
敏感词服务 (Sensitive Word Service)：
词库管理：支持动态增删改查，支持多级分类。
匹配引擎：高性能文本匹配算法。
API接口：供审核流程调用。
AI审核能力引擎：
文本分析API：集成NLP服务（如 spaCy, HanLP, 或第三方云服务如阿里云内容安全、腾讯云天御），进行分词、词性标注、情感分析、文本分类、可读性评估。
图像分析API：集成图像识别服务（如 OpenCV, 或第三方云服务），进行物体识别、OCR、色情/暴恐识别、人脸识别。
相似度计算服务：实现文本和图片的相似度比对算法。
规则引擎 (Rule Engine)：如 Drools, EasyRules 或自定义实现，用于灵活配置和执行复杂的审核逻辑。
人工审核工作台 (Frontend + Backend API)：Web应用，提供给审核员操作。
数据存储 (Database)：存储审核配置、词库、审核记录、内容状态等。
4.2 第三方服务集成
商业内容安全服务：考虑集成成熟的第三方内容安全服务（如网易易盾、腾讯云内容安全、百度AI内容审核等），它们通常拥有更全面的敏感词库、更强大的AI模型和更及时的风险事件响应能力。
版权检测服务：对于图片和文本，可以考虑集成专业的版权检测API，辅助判断原创性。
4.3 接口设计 (示例)
POST /api/v1/audit/submit_task: 提交内容进行审核。
GET /api/v1/audit/tasks: 获取待审核任务列表（供人工审核工作台）。
POST /api/v1/audit/tasks/{task_id}/decide: 提交人工审核决策。
GET /api/v1/audit/rules: 获取审核规则配置。
POST /api/v1/audit/feedback: 提交审核反馈（如误判申诉）。
5. 人工审核工作台
5.1 功能需求
任务列表与分配：
展示待审核、审核中、已审核等状态的任务。
支持按优先级、类型、来源账号等筛选和排序。
系统自动分配任务，或支持主管手动分配。
内容详情展示：
清晰展示待审核内容的标题、正文、图片、作者、来源等信息。
机审标记的风险点（如敏感词、疑似重复段落）应高亮显示。
提供原始内容链接或预览。
辅助信息展示：
显示机审的详细结果（各维度评分、触发的规则）。
提供相关账号信息（如账号定位、历史违规记录）。
快速访问事实核查工具或知识库。
审核操作：
一键“通过”、“拒绝”、“退回修改”。
对于“拒绝”和“退回修改”，必须填写理由或修改建议（可预设模板）。
支持对内容进行简单编辑（如修正错别字、删除敏感片段）。
支持添加标签或备注。
审核记录与追溯：
记录每次审核的操作人、时间、决策、理由。
支持查看历史审核记录。
效率统计与监控：
个人审核量、平均审核时长等数据统计。
5.2 界面设计概要 (UX)
简洁明了，突出核心信息。
操作便捷，减少点击次数。
风险提示醒目。
支持快捷键操作。

在 rules/头条/07-db-schema.md 中定义的 contents 表基础上，增加审核相关字段：

ALTER TABLE contents
    ADD COLUMN audit_status VARCHAR(20) DEFAULT 'pending_audit', -- pending_audit, auto_passed, pending_manual_audit, manual_passed, manual_rejected, revising

    ADD COLUMN audited_at TIMESTAMP; -- 审核完成时间

6.2 audit_logs 表 (可选，用于详细审计)
如果需要非常详细的审核步骤和历史记录，可以创建一个独立的审核日志表：

CREATE TABLE audit_logs (
    id UUID DEFAULT uuid_generate_v4() PRIMARY KEY,
    content_id UUID REFERENCES contents(id) ON DELETE CASCADE,
    audit_step VARCHAR(50) NOT NULL, -- e.g., 'auto_sensitive_check', 'manual_fact_check'
    status VARCHAR(20) NOT NULL, -- 'success', 'failed', 'warning'
    message TEXT,
    details JSONB, -- 该步骤的具体结果
    auditor_type VARCHAR(20) DEFAULT 'system', -- 'system', 'manual'
    auditor_id VARCHAR(100), -- 系统模块名或人工审核员ID
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_audit_logs_content_id ON audit_logs(content_id);
这个表可以记录每次自动化检查的结果，以及人工审核的每一步操作。

7. 监控与反馈机制
7.1 监控指标
机审性能：平均处理时长、QPS、API调用成功率。
机审准确性：
召回率 (Recall)：识别出的风险内容 / 总的真实风险内容。
精确率 (Precision)：识别出的风险内容 / 机审判断为风险的内容。
误报率 (False Positive Rate)：正常内容被误判为风险的比例。
漏报率 (False Negative Rate)：风险内容被误判为正常的比例。
人工审核效率：人均审核量、平均审核时长、超时任务比例。
人工审核一致性：不同审核员对同一类型内容审核结果的一致性（可通过抽样复审评估）。
审核规则触发频率：哪些规则最常被触发，哪些规则效果不佳。
内容发布后表现：因审核疏漏导致下架、处罚、用户投诉的比例。
7.2 反馈闭环
定期报告：生成审核日报、周报，分析趋势和问题。
案例分析：对典型的误判、漏判案例进行复盘，找出原因。
规则与模型优化：
根据漏判的敏感词，及时更新词库。
根据误判情况，调整AI模型参数或规则引擎阈值。
优化人工审核指南和培训材料。
审核员绩效：建立基于审核准确率和效率的审核员绩效评估体系。
申诉与复核机制：为内部运营团队或内容创作者提供对审核结果的申诉渠道，并建立复核流程。
8. 演进与优化方向
智能化审核：引入更先进的机器学习模型，例如基于上下文理解的风险识别、细粒度情感分析、隐晦含义识别等。
动态风险感知：结合实时热点和舆情，动态调整审核策略和敏感度。
用户画像辅助审核：结合发布账号的用户画像和历史行为，进行个性化风险评估。
多模态内容审核：增强对视频、音频内容的审核能力。
审核知识库构建：沉淀审核案例、规则、经验，形成知识库，辅助培训和决策。


对“审核策略与规则”进行了细化讨论。

主要细化点包括：

自动化合规性检查：AIGC标注识别、版权信息检查方案、外部链接检测技术。
敏感词检测：分级分类管理、动态更新机制、图片审核项、变体词处理技术。
原创性检测：文本和图片相似度比对库策略与阈值设定。
质量评估：更具体的文本和图片质量指标。
风险分类与评分：特征工程、权重配置或模型训练的选择、风险等级定义。
人工审核标准：针对特定内容类型的指南、AIGC内容的特别关注点、审核SLA、培训考核及申诉流程。
